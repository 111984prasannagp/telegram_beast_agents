# ⚡ n8n Automation

Planned workflows:

- 🎫 New ticket → notify support
- 🚨 High-priority ticket → immediate alert
- ⭐ Feedback → analytics
- 🔔 Pending ticket → follow-up
- 📊 Daily support report
- ✅ Resolved ticket → customer notification

Credentials belong in n8n or environment secrets, never in Git.
